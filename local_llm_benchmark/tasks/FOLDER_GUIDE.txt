# tasks folder guide

This folder contains the frozen HEPToolBench v1.2 task families.

Task-family directories
-----------------------

- `analysis/`
- `delphes/`
- `lhe/`
- `mg_basic/`
- `mg_debug/`
- `mg_debug_structured/`
- `mg_parse/`
- `mg_runcard/`
- `mg_runcard_structured/`
- `mg_structured/`
- `mg_workflow/`
- `mg_workflow_structured/`
- `pythia/`
- `repro/`
- `scan/`

Depending on the task, a task definition can contain prompts, input artifacts,
metadata, schemas or expected-artifact descriptions, and deterministic scorer
code.

Users normally should not execute task files directly.

Run a selected task through the benchmark launcher:

```text
./run_benchmark.sh --models MODEL_NAME --tasks TASK_ID --yes
```

Or, from `local_llm_benchmark/`, use the task-level runner:

```text
python3 runners/run_ollama_task.py --model MODEL_NAME --task TASK_ID
```

The frozen suite contains 28 main tasks plus 3 structured-debug extension
tasks. See `../SUITE_SCOPE.md` for the formal suite definition.
