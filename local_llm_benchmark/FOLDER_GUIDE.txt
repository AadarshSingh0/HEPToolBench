HEPToolBench public folder guide
================================

This directory contains the frozen HEPToolBench v1.2 benchmark implementation.
HEPToolBench is the benchmark only; the companion HEPLocalAgent project is
maintained separately.

Main folders
------------

tasks/
  Benchmark task families. Individual task directories contain prompts,
  inputs, metadata, expected artifact definitions, and deterministic scorers.

runners/
  Model execution and submission-evaluation code. This includes the direct
  Ollama HTTP transport, Ollama generation-setting handling, and API runners.

scripts/
  Result aggregation, benchmark auditing, API batch helpers, and analysis
  utilities.

docs/
  User documentation for running models and understanding the Ollama HTTP
  evaluation transport.

tests/
  Offline unit tests for the Ollama HTTP runner and generation controls.

submissions/
  Runtime model-generated artifacts. New submissions should normally remain
  untracked by Git.

runs/
  Isolated benchmark invocations generated by run_benchmark.py. Ignored by
  Git in the public repository.

results/
  Curated public research artifacts plus locally generated result summaries.
  Runtime cumulative files such as all_runs_long.csv are ignored by Git.

Important top-level files
-------------------------

README.md
  Benchmark overview and command examples.

VERSION
  Frozen benchmark version.

SUITE_SCOPE.md
  Definition of the 28-task main suite and 31-task full suite.

api_model_matrix.tsv
  Provider/API model configuration used by API-oriented runners.

run_benchmark.py
  Main benchmark orchestration program.

smoke_test_public.sh
  Public installation/runtime smoke checks.

MANIFEST.sha256
  SHA-256 manifest for tracked benchmark-release files.

Beginner commands
-----------------

From the repository root:

  ./install.sh
  ./run_benchmark.sh

The guided benchmark runner can detect available Ollama models, select a task
suite, create a separate run directory, preserve raw/scored artifacts, update
CSV summaries, and resume interrupted runs.

Noninteractive example
----------------------

  ./run_benchmark.sh \
    --models llama3:8b qwen3:8b \
    --suite full31 \
    --repeats 1 \
    --yes

Remote Ollama example
---------------------

  ./run_benchmark.sh \
    --ollama-host http://HOST:11434 \
    --models all-installed \
    --suite full31 \
    --yes

Ollama serving controls
-----------------------

The launcher supports --num-ctx, --think, --temperature, --seed, and
--num-predict. See docs/RUN_LOCAL_MODELS.md and
docs/OLLAMA_HTTP_TRANSPORT.md for details.

Single-task developer example
-----------------------------

From local_llm_benchmark/:

  python3 runners/run_ollama_task.py \
    --task mg_basic_001 \
    --model llama3:8b \
    --output-root /tmp/heptoolbench_single_task

Safety
------

Do not commit API keys, tokens, model weights, private logs, generated event
files, machine-specific paths, or ordinary runtime runs/submissions.
