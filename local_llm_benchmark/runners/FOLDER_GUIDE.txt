# runners folder guide

This folder contains model execution, transport, and artifact-evaluation code.

Primary local-model path
------------------------

run_ollama_task.py
  Primary task-level Ollama runner used by the current public benchmark.

ollama_http_transport.py
  Sends non-streaming `/api/generate` requests and records request/response
  metadata used by the benchmark integrity checks.

ollama_generation_settings.py
  Parses and validates optional Ollama generation settings such as reasoning,
  temperature, seed, and generation-token budget.

io_utils.py
  Shared runner input/output helpers.

evaluate_submission.py
  Evaluates an existing model-generated artifact with the deterministic scorer
  for a selected benchmark task.

structured_mg_builder.py
  Deterministic helper used by structured MadGraph evaluation workflows.

Additional runner
-----------------

run_ollama_task2.py
  Additional local-runner entry point retained in the repository. The normal
  public benchmark workflow uses `run_ollama_task.py` through the top-level
  `run_benchmark.sh` launcher.

Usage
-----

Normal users should run models from the repository root with:

```text
./run_benchmark.sh
```

Use environment variables for provider API credentials. Never hard-code or
commit API keys or tokens.
