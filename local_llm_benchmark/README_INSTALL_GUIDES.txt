# How to install these folder guides

Option 1: unzip directly into the public repository folder.

From the directory containing this zip file, run:

    unzip -o heptoolbench_folder_guides.zip -d ~/Benchmark/HEPToolBench-public

This will place:
- FOLDER_GUIDE.txt
- docs/FOLDER_GUIDE.txt
- runners/FOLDER_GUIDE.txt
- scripts/FOLDER_GUIDE.txt
- tasks/FOLDER_GUIDE.txt
- paper_results/FOLDER_GUIDE.txt

Option 2: copy manually.

Open the zip and copy each FOLDER_GUIDE.txt into the matching folder.

Optional:
Use TASK_SUBFOLDER_GUIDE_TEMPLATE.txt as a template if you want a guide inside individual task subfolders.
