# docs folder guide

This folder contains the main user and reproducibility documentation for
HEPToolBench.

Files
-----

how_to_test_a_model.md
  Short task-level instructions for checking a model with HEPToolBench.

RUN_LOCAL_MODELS.md
  Complete guide for guided and noninteractive Ollama benchmark runs,
  remote Ollama servers, generated files, resume, and generation controls.

OLLAMA_HTTP_TRANSPORT.md
  Description of the non-streaming Ollama HTTP evaluation path, recorded
  provenance, integrity safeguards, and associated offline tests.

Related documentation
---------------------

../SUITE_SCOPE.md
  Defines the `main28` and `full31` benchmark scopes and reporting rules.

../FOLDER_GUIDE.txt
  Maps the complete benchmark directory structure.

Recommended starting point
--------------------------

New users should begin with the repository root README and then read
RUN_LOCAL_MODELS.md.
